# Руммикуб на одном устройстве

Статическая офлайн-версия Руммикуба для 2–4 игроков, которые сидят рядом
и передают друг другу один телефон. Никакого сервера, аккаунтов и интернета:
всё считается прямо в браузере, партия сохраняется в память устройства.

## Как играть

1. Выберите количество игроков и введите имена.
2. Перед каждым ходом появляется экран «Передайте устройство» — чужие фишки
   при этом не видны. Игрок нажимает «Я готов» и видит только свою руку.
3. Нажмите на фишки (можно несколько сразу), затем:
   * **＋ Новый набор** — выложить их отдельным набором;
   * **цифра слева от набора** — доложить их в этот набор;
   * **На руку** — вернуть свои сегодняшние фишки обратно.
4. «Ход сделан» проверяет стол. Если что-то собрано неверно, игра скажет что
   именно и ход не завершится.
5. Ходить нечем — «Взять фишку»: все перестановки отменяются, ход уходит дальше.

Правила стандартные: группа — 3–4 фишки одного числа разных цветов, ряд — 3 и
больше фишек одного цвета подряд, джокер заменяет любую фишку. Первый выход —
минимум 30 очков только из своих фишек, до него чужие наборы трогать нельзя.
После выхода стол можно перестраивать как угодно, лишь бы к концу хода все
наборы были правильными и хотя бы одна фишка ушла с руки.

Победитель получает сумму фишек, оставшихся у соперников; остальные — эту сумму
со знаком минус. Джокер на руке стоит 30.

## Публикация на GitHub Pages

Репозиторий — обычный статический сайт, сборка не нужна.

**Вариант 1. Прямо из ветки.** Settings → Pages → Source: *Deploy from a branch*,
ветка `main`, папка `/ (root)`. Через минуту игра будет доступна по адресу
`https://<логин>.github.io/<репозиторий>/`.

**Вариант 2. Через Actions.** В репозитории уже лежит
`.github/workflows/pages.yml`: он прогоняет тесты и публикует сайт при пуше в
`main`. Для него нужно один раз выбрать Settings → Pages → Source: *GitHub Actions*.

Все пути в проекте относительные, поэтому игра работает и в подпапке
(`/<репозиторий>/`), и в корне домена.

## Офлайн и установка на телефон

`sw.js` кэширует все файлы игры при первом открытии — дальше она работает без
сети. Через меню браузера («Добавить на главный экран») игра ставится как
приложение и открывается на весь экран без адресной строки.

После изменения файлов поднимите `VERSION` в `sw.js`, иначе у игроков останется
старая версия из кэша.

## Устройство проекта

```
index.html          разметка всех экранов
styles.css          оформление, размеры фишек, тёмная «сукно»-тема
js/rules.js         колода, разбор наборов и рядов, стоимость фишек
js/game.js          состояние партии, ходы, проверка хода, счёт
js/hint.js          поиск очевидного хода для подсказки
js/app.js           экраны, выделение фишек, кнопки
sw.js               офлайн-кэш
tests/              тесты правил и ходов
```

Игровая логика (`rules.js`, `game.js`, `hint.js`) не знает про DOM, поэтому
проверяется обычными тестами.

## Локальный запуск и тесты

ES-модули требуют http, поэтому просто открыть `index.html` файлом не получится:

```bash
python3 -m http.server 8000    # затем http://localhost:8000
npm test                       # тесты правил и ходов (нужен Node 18+)
```
